# Loan Bazar - Admin Control Portal

A full-featured Credit Administrator Dashboard for **Loan Bazar Digital Lending Platform**, built with React 19, TypeScript, and Vite.

## 🚀 Key Features

- **Applicant Review & Verification:** Real-time stream of loan applications submitted from the Loan Bazar mobile app.
- **KYC & Document Inspection:** Modal inspection of Live Selfie, House Front Photo, Aadhaar Front/Back, PAN Card, and Bank statements.
- **Custom Credit Underwriting & Interest Rate Setting:** Real-time calculator supporting 7/15-day micro loans and 1-12 month installment loans with customizable annual interest rate percentages (`% p.a.`).
- **AutoPay Mandate Status Tracking:** Live indicators for UPI AutoPay / e-Mandate registrations with payment reference IDs.
- **Direct Disbursal Trigger:** One-click disbursal execution to applicant bank accounts.
- **Fraud Prevention & Blacklisting:** Instantly block suspicious borrowers and accounts.

## 🛠️ Tech Stack

- **Frontend:** React 19, TypeScript, Vite
- **Backend & Database:** Firebase Firestore (Realtime DB), Firebase Storage
- **Styling:** Modern responsive CSS with Lucide React Icons
- **Deployment:** Compatible with Vercel, Netlify, Firebase Hosting, Cloudflare Pages

## 📦 Getting Started

1. **Install Dependencies:**
   ```bash
   npm install
   ```

2. **Run Local Development Server:**
   ```bash
   npm run dev
   ```
   Opens on `http://localhost:5173/`

3. **Build for Production:**
   ```bash
   npm run build
   ```
